# 生产就绪功能(Production-ready Features)

Spring Boot 包含许多附加功能，可帮助您在将应用程序部署到生产环境时对其进行监控和管理。您可以选择通过 HTTP 端点或 JMX 来管理和监控应用程序。审计、健康检查和指标收集功能也可以自动应用于您的应用程序。

# 1.启用生产就绪功能

spring-boot-actuator 模块提供了 Spring Boot 所有生产就绪的功能。推荐启用这些功能的方式是添加对 spring-boot-starter-actuator 启动器的依赖。

## 执行器的定义 
执行器是一个制造术语，指的是用于移动或控制某物的机械装置。执行器可以从微小的变化中产生大量的运动。

要将执行器添加到基于 Maven 的项目中，请添加以下启动器依赖项：

```bash
<dependencies>
	<dependency>
		<groupId>org.springframework.boot</groupId>
		<artifactId>spring-boot-starter-actuator</artifactId>
	</dependency>
</dependencies>
```
对于 Gradle，请使用以下声明：

```bash
dependencies {
	implementation 'org.springframework.boot:spring-boot-starter-actuator'
}
```

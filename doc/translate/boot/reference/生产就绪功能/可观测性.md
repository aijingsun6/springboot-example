# 可观测性(Observability)

可观测性是指从外部观察运行系统内部状态的能力。它由三大支柱组成：日志、指标和追踪。对于指标和追踪，Spring Boot 使用 [Micrometer](https://docs.micrometer.io/micrometer/reference/observation) 可观测性。要创建自己的观测（这将生成指标和追踪），可以注入一个 [ObservationRegistry](https://javadoc.io/versions/io.micrometer/micrometer-observation)


```bash
import io.micrometer.observation.Observation;
import io.micrometer.observation.ObservationRegistry;

import org.springframework.stereotype.Component;

@Component
public class MyCustomObservation {

	private final ObservationRegistry observationRegistry;

	public MyCustomObservation(ObservationRegistry observationRegistry) {
		this.observationRegistry = observationRegistry;
	}

	public void doSomething() {
		Observation.createNotStarted("doSomething", this.observationRegistry)
			.lowCardinalityKeyValue("locale", "en-US")
			.highCardinalityKeyValue("userId", "42")
			.observe(() -> {
				// Execute business logic here
			});
	}

}
```

低基数标签将添加到指标和追踪中，而高基数标签仅添加到追踪中。 
类型为 ObservationPredicate、GlobalObservationConvention、ObservationFilter 和 ObservationHandler 的 Bean 将自动注册到 ObservationRegistry 中。此外，您还可以注册任意数量的 ObservationRegistryCustomizer Bean 以进一步配置注册表。 
JDBC 的可观测性可以通过一个单独的项目进行配置。[Datasource Micrometer](https://github.com/jdbc-observations/datasource-micrometer) 项目提供了一个 Spring Boot 启动器，可在调用 JDBC 操作时自动创建观测。更多信息请参阅参考[文档](https://jdbc-observations.github.io/datasource-micrometer/docs/current/docs/html/) 
R2DBC 的可观测性已集成到 Spring Boot 中。要启用它，请在项目中添加 io.r2dbc:r2dbc-proxy 依赖项。


# 上下文传播(Context Propagation)

可观测性支持依赖于 Context Propagation 库，用于在跨线程和响应式管道中传递当前观察。默认情况下，ThreadLocal 值不会在响应式操作符中自动恢复。此行为可通过 `spring.reactor.context-propagation` 属性进行控制，该属性可设置为 `auto` 以启用自动传播。

如果您正在使用 `@Async` 方法，并且 `AsyncTaskExecutor` 是自动配置的，则必须通过 `spring.task.execution.propagate-context` 属性显式选择上下文传播。

如果您自己配置了 `AsyncTaskExecutor`，则需要注册一个 `ContextPropagatingTaskDecorator` bean，如下例所示：

```bash

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.core.task.support.ContextPropagatingTaskDecorator;

@Configuration(proxyBeanMethods = false)
class ContextPropagationConfiguration {

	@Bean
	ContextPropagatingTaskDecorator contextPropagatingTaskDecorator() {
		return new ContextPropagatingTaskDecorator();
	}

}
```


有关观测的更多详细信息，请参阅 [Micrometer Observation](https://docs.micrometer.io/micrometer/reference/observation)


# Common Tags
通用标签通常用于对运行环境（如主机、实例、区域、堆栈等）进行维度下钻。通用标签作为低基数标签应用于所有观测数据，可以按照以下示例进行配置：

```yaml
management:
  observations:
    key-values:
      region: "us-east-1"
      stack: "prod"
```

前面的示例为所有观测值分别添加了区域（us-east-1）和堆栈（prod）标签。

# Preventing Observations(防止观察行为)

如果您希望防止某些观察结果被报告，可以使用管理.observations.enable属性：

```bash

management:
  observations:
    enable:
      denied:
        prefix: false
      another:
        denied:
          prefix: false
```


前面的示例将阻止所有名称以 denied.prefix 或 another.denied.prefix 开头的观察项。 
如果您希望阻止 Spring Security 报告观察项，请将属性 `management.observations.enable.spring.security` 设置为 `false`。 
如果您需要对观察项的阻止有更精细的控制，可以注册类型为 `ObservationPredicate` 的 bean。只有当所有 `ObservationPredicate` bean 对该观察项返回 `true` 时，才会报告该观察项。

```
import io.micrometer.observation.Observation.Context;
import io.micrometer.observation.ObservationPredicate;

import org.springframework.stereotype.Component;

@Component
class MyObservationPredicate implements ObservationPredicate {

	@Override
	public boolean test(String name, Context context) {
		return !name.contains("denied");
	}

}

```
前面的示例将阻止所有名称中包含“denied”的观测值。

# 自动配置(Auto-configuration)

Spring Boot 的自动配置功能会根据你添加的 jar 依赖项，尝试自动配置你的 Spring 应用程序。例如，如果你的类路径中包含 HSQLDB，并且你没有手动配置任何数据库连接 bean，那么 Spring Boot 会自动配置一个内存数据库。

你需要通过在某个 `@Configuration` 类中添加 `@EnableAutoConfiguration` 或 `@SpringBootApplication` 注解来启用自动配置。

你只能添加一个 `@SpringBootApplication` 或 `@EnableAutoConfiguration` 注解。我们通常建议你只将其中一个注解添加到主 `@Configuration` 类中。

逐步替换自动配置
自动配置是无侵入性的。在任何时候，你都可以开始定义自己的配置来替换自动配置的特定部分。例如，如果你添加了自定义的 DataSource bean，默认的嵌入式数据库支持就会自动退让。

如果你需要了解当前正在应用哪些自动配置以及原因，可以在启动应用程序时使用 --debug 开关。这样做会为一些核心日志记录器启用调试日志，并将条件报告记录到控制台。

禁用特定的自动配置类
如果你发现正在应用一些你不想要的特定自动配置类，可以使用 @SpringBootApplication 的 exclude 属性来禁用它们，如下例所示：


```java

import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.boot.jdbc.autoconfigure.DataSourceAutoConfiguration;

@SpringBootApplication(exclude = { DataSourceAutoConfiguration.class })
public class MyApplication {

}
```

如果该类不在类路径中，您可以使用注解的 `excludeName` 属性并指定完全限定名。如果您更倾向于使用 `@EnableAutoConfiguration` 而不是 `@SpringBootApplication`，同样可以使用 `exclude` 和 `excludeName`。最后，您还可以通过 `spring.autoconfigure.exclude` 属性来控制要排除的自动配置类列表。

您可以在注解级别定义排除项，也可以通过属性来定义。

尽管自动配置类是公开的，但其中唯一被视为公共 API 的部分是类的名称，该名称可用于禁用自动配置。这些类的实际内容（例如嵌套的配置类或 bean 方法）仅供内部使用，我们不建议直接使用它们。

自动配置包
自动配置包是指在扫描实体和 Spring Data 仓库等资源时，各种自动配置特性默认会查找的包。`@EnableAutoConfiguration` 注解（无论是直接使用还是通过 `@SpringBootApplication` 中的存在）决定了默认的自动配置包。您可以使用 `@AutoConfigurationPackage` 注解来配置额外的包。

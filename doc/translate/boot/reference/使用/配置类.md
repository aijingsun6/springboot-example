# 配置类（Configuration Classes）

Spring Boot 倾向于使用基于 Java 的配置。尽管可以使用 SpringApplication 配合 XML 源，但我们通常建议将主要配置源设为一个单独的 @Configuration 类。通常，定义了 main 方法的类是作为主 @Configuration 类的合适候选。

许多在网络上发布的 Spring 配置示例都使用了 XML 配置。如果可能，请始终尝试使用等效的基于 Java 的配置。查找 Enable* 注解可以作为一个良好的起点。


导入额外的配置类
您无需将所有 @Configuration 注解都放在一个类中。可以使用 @Import 注解来导入额外的配置类。或者，您也可以使用 @ComponentScan 来自动扫描并加载所有 Spring 组件，包括 @Configuration 类。

导入 XML 配置
如果您必须使用基于 XML 的配置，我们建议您仍然从一个 @Configuration 类开始。然后，您可以使用 @ImportResource 注解来加载 XML 配置文件。

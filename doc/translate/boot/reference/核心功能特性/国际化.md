# 国际化(Internationalization)

Spring Boot 支持本地化消息，以便您的应用程序能够满足不同语言偏好的用户。默认情况下，Spring Boot 会在类路径的根目录下查找是否存在名为 messages 的资源包。


自动配置在配置的资源包（默认情况下为 messages.properties）的默认属性文件可用时生效。如果您的资源包仅包含特定语言的属性文件，则需要添加默认文件。如果未找到与任何配置的基本名称匹配的属性文件，则不会自动配置 MessageSource。

资源包的基本名称以及其他一些属性可以通过 spring.messages 命名空间进行配置，如下例所示：


```bash
spring.messages.basename=messages, config.i18n.messages
spring.messages.common-messages=classpath:my-common-messages.properties
spring.messages.fallback-to-system-locale=false
```

- `spring.messages.basename` 属性支持一个位置列表，可以是包限定符，也可以是从类路径根目录解析的资源。
- `spring.messages.common-messages` 属性支持一个属性文件资源列表




请参阅 [MessageSourceProperties](https://docs.spring.io/spring-boot/api/java/org/springframework/boot/autoconfigure/context/MessageSourceProperties.html) 以获取更多支持的选项。
